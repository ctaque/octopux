# Examples

Runnable projects in [`examples`](https://github.com/ctaque/octopux/tree/main/examples), with [Hoppscotch](https://hoppscotch.io/) request collections:

| Example | Shows |
| --- | --- |
| [`simple`](https://github.com/ctaque/octopux/tree/main/examples/simple) | Traits implemented by hand, with `gen_endpoint!` |
| [`pagination`](https://github.com/ctaque/octopux/tree/main/examples/pagination) | A paginated `list` |
| [`openapi`](https://github.com/ctaque/octopux/tree/main/examples/openapi) | sqlx models with Swagger UI |
| [`graphql`](https://github.com/ctaque/octopux/tree/main/examples/graphql) | Authors, books and pages with GraphQL and relations |
| [`graphql_auth`](https://github.com/ctaque/octopux/tree/main/examples/graphql_auth) | GraphQL with JWT authentication |
| [`relations_filters_sort`](https://github.com/ctaque/octopux/tree/main/examples/relations_filters_sort) | Relations, filters and sort (PostgreSQL) |
| [`postgis`](https://github.com/ctaque/octopux/tree/main/examples/postgis) | PostGIS points and polygons as GeoJSON, spatial filters, and a `nearby` route with `ST_DWithin` |
| [`before_save`](https://github.com/ctaque/octopux/tree/main/examples/before-save) | `BeforeSave` hooks: password hashing on create, email validation |
| [`reverse_engineering`](https://github.com/ctaque/octopux/tree/main/examples/reverse_engineering) | An API generated by `octopux-reverse` from ~100 tables |
